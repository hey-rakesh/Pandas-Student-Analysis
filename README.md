# 📊 Pandas Student Analysis

A beginner-friendly **Data Analysis project using Python and Pandas** to analyze student performance data.

This project demonstrates practical Pandas operations such as filtering, grouping, sorting, aggregation, and finding top-performing students.

## 🚀 Features

* 📌 Load student data from CSV
* 📌 Analyze student marks
* 📌 Find average marks
* 📌 Find highest and lowest marks
* 📌 Find the topper
* 📌 Filter students based on marks
* 📌 Count placed and non-placed students
* 📌 Analyze department and city-wise data
* 📌 Practice Pandas DataFrame operations
